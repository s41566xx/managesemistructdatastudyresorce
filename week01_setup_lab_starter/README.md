# Week 1 Practical

## Start here

1. Unzip the practical folder.
2. Open the extracted folder in VS Code.
3. Open `notebooks/week01_setup_and_library_demo_student.ipynb`.
4. Select a Python 3.10+ kernel and run the notebook from top to bottom. If
   VS Code says `ipykernel` is required, click **Create a Python Environment**.
   Do not use **Quick Create** if it shows Python 3.9. Choose **venv**, select
   Python 3.10+, then select the new `.venv` kernel.

The first notebook cell installs the required libraries into the selected
kernel. The normal setup does not require a terminal. If that cell cannot
install packages in your Python environment, follow the short `.venv` Plan B
in the practical handout.

## What you will do

- Check that Python, Jupyter and the required libraries work.
- Claim and test your individual course API key.
- Make a first chat request and embedding request.
- Run a small embed, rank and judge pipeline that previews the course.

## Included files

- `notebooks/week01_setup_and_library_demo_student.ipynb`: guided setup and
  practical activities
- `requirements.txt`: required Python packages

Keep the extracted practical folder after class so you can reuse the same
working environment in later weeks.
